## はじめまして

石川県金沢市に住んでいます。普段は翻訳の仕事をしていて、そのかたわら台所と庭を相手に暮らしています。この町に来て四十二年、いまだに近江町市場のアーケードに入るとほっとします。

- 🏠 片町はずれ、築四十年の家。冬は雪吊りの季節が待ち遠しい
- 🐟 買い物は近江町市場。雨の日も濡れずに魚が買えるのが小さな幸運
- ✍️ 書くのは月に二度ほど。たいそうな話ではなく、台所と町のこと
- 🖋 推敲は紙の上で。こちらに上がるのは二番目の草稿です
- 💻 サイトは HTML と CSS を手で書いています。プログラムは得意ではありません
