# 小波（こなみ）

金沢・片町はずれから、二十四節気にあわせて日々の記録を書いています。

## はじめまして

石川県金沢市に住んでいます。普段は翻訳の仕事をしていて、そのかたわら台所と庭を相手に暮らしています。この町に来て四十二年、いまだに近江町市場のアーケードに入るとほっとします。雨の日でも濡れずに魚が買えるというのは、小さな、しかし毎回うれしい幸運です。

書いているのは、たいそうな話ではありません。秋刀魚を三尾買ったこと、兼六園の雪吊りの針金を数えてしまったこと、台風の前に軒下の道具をしまう順番のこと。そういうのを二十四節気の目盛りに沿って、月に二度ほど。
